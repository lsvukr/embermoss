# EmberMoss

Public website of EmberMoss, served by GitHub Pages from the `main` branch:
https://lsvukr.github.io/embermoss/

- `index.html`: home page with the list of apps.
- `notevision/privacy/index.html`: NoteVision privacy policy, linked from Google Play and from the app.

Plain HTML and CSS, no build step. `.nojekyll` tells GitHub Pages to serve the files as they are.
